GameLoop Keymapping Fix — Client Installer
==========================================

1. Download GameloopFix-Installer.zip from GitHub Releases:
   https://github.com/sedaimanish/Gameloop-Keymapping-Fix/releases/latest

2. Extract the zip anywhere.

3. Right-click Install-GameloopFix.bat -> Run as administrator.

4. Choose "Full install".

5. Relaunch GameLoop and PUBG.

The installer downloads patched files from the latest GitHub Release automatically.
You do not need Python.

Restore: run the installer again and choose option 3 (Restore backup).
